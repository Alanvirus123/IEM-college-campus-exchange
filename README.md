# UniLoop — Campus Second-Hand Exchange Platform

> A peer-to-peer student marketplace built with **Next.js 14**, **TypeScript**, and **Tailwind CSS**, styled using **Google Stitch** modern AI design principles.

🌐 **Live Deployment on Vercel**:  
👉 **[https://campusexchange-six.vercel.app/](https://campusexchange-six.vercel.app/)**

---

## 📚 Overview

UniLoop allows university students to **buy, trade, or giveaway** college essentials instead of buying brand new:
- **Textbooks & Course Notes** (Bio, Chem, Calculus, CS, etc.)
- **Electronics & Workstation Tech** (4K USB-C monitors, graphing calculators, keyboards)
- **Dorm Furniture** (Ergonomic chairs, desks, standing converters, mini-fridges)
- **Lab & Science Equipment** (Microscopes, oscilloscopes, molecular modeling sets)

---

## ✨ Features

- **Google Stitch Aesthetic**: High-contrast typography, pill search bar, smooth elevation, category pills, and responsive layout.
- **Search & Multi-Filter**: Real-time search across item titles, course codes (e.g. `BIO101`, `EE240`), descriptions, tags, and categories.
- **Campus Trade & Barter Intent**: Sellers can specify items they wish to exchange for (e.g. trading a microscope for an iPad pencil).
- **Direct Campus Chat & Offers**: In-app live negotiation thread where buyers can message sellers and submit dollar offers.
- **Post an Item Modal**: Fast listing creation supporting sale price, campus giveaway, or barter items.
- **Saved Watchlist**: Bookmark listings to track deals and meetup availability.

---

## 🛠 Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Hosting & CI/CD**: Vercel

## 💻 Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/Alanvirus123/uniloop-campus-exchange.git
   cd uniloop-campus-exchange
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
